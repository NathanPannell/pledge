Install Spare in Chrome.

Use desktop Chrome. After this one-time setup, your round-up appears directly in OpenRouter’s Add Credits window. Stripe opens separately when you confirm a payment at C$5.

  1. Download the extension, then unzip it.
  2. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the unzipped folder.
  3. Open Spare’s extension popup and paste the connection code below.
  4. Open OpenRouter’s Credits page and choose Add Credits. Spare will appear beside the final purchase total.

Codes expire after five minutes. Your card details are never shared with the extension.
